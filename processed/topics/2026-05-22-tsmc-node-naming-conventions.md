TSMC's semiconductor process node naming scheme has shifted from nanometer-based labels (N7, N5, N3) to angstrom-based labels for sub-2nm nodes.

### Key Node Designations
- **A13 Node**: Refers to a ~1.3nm-class process node in TSMC's roadmap, positioned several generations beyond the 2nm (N2) node.
- **N2U Node**: A specialized variant/derivative of the 2nm (N2) base node, tailored for specific power, performance, or area optimization targets.
